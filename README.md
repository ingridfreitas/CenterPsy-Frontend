## 📌 Sobre o Projeto

O **CenterPsy** é um projeto de site institucional desenvolvido no âmbito do **Bootcamp Desenvolvimento de Sistemas Web Avançados Front-End** da Unisagrado. 

O projeto nasceu de uma **demanda real** identificada junto ao psicólogo **Gilson Santos** (responsável pela clínica em São Manuel - SP). O objetivo principal é estabelecer a presença digital institucional da clínica, transmitindo acolhimento, clareza e profissionalismo, além de disponibilizar um canal direto de contato por mensagens para futuros pacientes.

---

## 🎨 Visual e Identidade da Interface

O design foi planejado para refletir a essência da abordagem humanista e fenomenológica na psicologia:
* **Paleta de Cores Sóbria e Acolhedora:** Tons profundos de azul petróleo combinados com detalhes em amarelo suave, transmitindo serenidade e confiança.
* **Componentes Responsivos:** Seções estruturadas para proporcionar uma experiência fluida tanto em computadores quanto em dispositivos móveis.
* **Seções Principais:**
  1. **Capa / Hero:** Apresentação institucional com destaque visual em arco e nota de presença.
  2. **A Abordagem:** Pilares do atendimento (Escuta atenta, clareza gentil, relação de confiança e pequenos movimentos).
  3. **Como Funciona:** Diretrizes transparentes sobre o fluxo terapêutico.
  4. **Sobre Mim:** Espaço dedicado à apresentação profissional e formação.
  5. **Primeiro Contato:** Formulário interativo para envio de mensagens seguras.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web modernas de front-end, sem a necessidade de banco de dados nesta etapa inicial:
* **Angular** — Framework estrutural para aplicações web.
* **TypeScript** — Superset JavaScript para lógica tipada e limpa.
* **CSS3 Moderno** — Flexbox, Grid Layout, variáveis e design responsivo.
* **HTML5 Semântico** — Foco em acessibilidade e SEO básico.
* **GitHub** — Controle de versão e versionamento de código.

## ⚙️ Como Executar o Projeto Localmente

Para rodar o projeto em sua máquina de desenvolvimento:

1. Clone o repositório: 
   ```bash 
   git clone https://github.com/ingridfreitasCenterPsy-Frontend.git
    ```

2. Entre na pasta: 
    ```bash
    cd CenterPsy-Frontend
    ```

3. Instale as dependências: 
   ``` bash
   npm install
   ```

4. Inicie o servidor: 
   ```bash 
   ng serve
   ```

5. Acesse no navegador: `http://localhost:4200/`
